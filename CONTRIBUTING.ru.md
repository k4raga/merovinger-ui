# Участие в разработке

Используйте Python 3.13 и новое виртуальное окружение.
Установите библиотеку из checkout и инструменты проверки:

~~~console
python -m pip install . pytest==9.2.0 build
python -c "from pathlib import Path; Path('.runtime').mkdir(exist_ok=True)"
python -m pytest -q tests --basetemp .runtime/pytest
~~~

На Linux без рабочего стола задайте `QT_QPA_PLATFORM=offscreen`.
После изменения исходников переустановите библиотеку,
чтобы тесты проверяли нужную установленную версию.

Держите изменения в границах UI-пакета. Предпочитайте одну содержательную
проверку изменённого поведения новой широкой матрице.
Сохраняйте допуск типизированных команд, текущую политику экспорта,
явное владение ресурсами и очистку.
Не добавляйте второе хранилище состояния, скрытый цикл событий
или обязательную зависимость от модели.

В pull request опишите конкретную проблему, получившееся поведение и проверки.
Согласованно обновляйте русскую и английскую документацию.
Для платформенных ошибок укажите ОС, Python и backend Qt
и приложите небольшой тестовый пример.
Не прикладывайте учётные данные, личные снимки экрана и данные других приложений.

Код, собственная документация и иллюстрации доступны под
[лицензией MIT](LICENSE). API альфа-версии может меняться;
обсудите изменение публичного API до его расширения.
