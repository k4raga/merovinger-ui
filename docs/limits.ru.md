# Возможности и ограничения альфа-версии

Merovinger UI — библиотека интеграции для Python 3.13 и PySide6.
Поставка сохраняет namespace импорта `agent_native`. Используйте отдельное
окружение: не устанавливайте её вместе с прежними `agent-native-ui` или
`agent-native-runner`, владеющими тем же namespace.

## Нативная область

Поддерживаются точные типы `QLabel`, `QPushButton`, `QLineEdit`,
`QListView`, `QCheckBox` и `QSpinBox`, а не произвольные подклассы.
Каждый должен занимать прямое место в QBoxLayout под переданным родительским
виджетом. Это не универсальный адаптер существующих приложений.

Подписи и кнопки используют обычный текст. Подключённые списки используют
стандартный текстовый делегат без встроенных и произвольных ячеек.
Редакторы — обычные однострочные контролы; неподдерживаемое оформление
отклоняется. Привязки и типизированные команды объявляются явно.
Если изменённую отрисовку нельзя безопасно связать с известным источником,
захват может быть запрещён.

## Только чтение и черновики

Представления только для чтения требуют объявлений без Actions и получают
ограниченное разрешение чтения. У них могут оставаться локальные черновики,
фокус и выбор. Наличие отрисованного контрола не даёт модели прав
на изменение предметных данных.

## Контекст и пиксели

Участвуют только зарегистрированные управляемые области. Запрещённая
или неподтверждённая зависимость отрисовки сейчас блокирует **весь PNG**;
маскирование отдельных участков не обещается. Проверяйте `visual_status`
и `images`: пакет не обязательно содержит изображение.

Текущая политика и срок действия проверяются перед передачей байтов.
Доверенный Python-код может скопировать полученные байты; библиотека не может
отозвать копии или подсчитать внешние вызовы провайдера.
Локальный bridge не изолирует вредоносный код самого приложения.

Согласованность контекста и кадра относится к опубликованному срезу состояния.
Она не доказывает успешность всех внешних эффектов.
Приём команды и завершение её сохранения различаются.

## Жизненный цикл и платформы

Работа ограничена и управляется явно. Завершение может ожидать CPU-кодировщик,
сохранение или представление, заимствующее ресурсы. Во время очистки сохраняйте
работающий цикл событий владельца; отмена не равна физическому завершению работы.

Проверка Windows ограничена протестированным окружением Windows 11 LTSC.
Ubuntu offscreen проверяет поведение Qt без подтверждения всех конфигураций
рабочего стола. Нативная macOS, произвольные семейства виджетов, полнота
доступности, все сочетания IME и платформ, промышленная нагрузка не заявляются.

Память, исполнение программ, подключения моделей и общий внешний API
не входят в UI-пакет. Адаптер модели предоставляет приложение.
