# Проверки

## Воспроизводимые проверки репозитория

Используйте новое окружение Python 3.13:

~~~console
python -m pip install . pytest==9.2.0 build
python -c "from pathlib import Path; Path('.runtime').mkdir(exist_ok=True)"
python -m pytest -q tests --basetemp .runtime/pytest
python examples/ui_agent/main.py --smoke --report .runtime/smoke.json
python -m build --wheel
~~~

Для Linux без рабочего стола задайте `QT_QPA_PLATFORM=offscreen` перед
тестами и примером. Для нативной проверки Windows используйте интерактивный
сеанс рабочего стола и backend Qt `windows`, а не offscreen или системную службу.

Набор содержит **14 самостоятельных сценариев**:

| Область | Сценарии | Проверяется |
| --- | ---: | --- |
| Runtime | 4 | Сохранение типизированной команды, разрешение чтения и восстановление; изоляция зависимостей; отказ при живом владельце; позднее подтверждение запуска |
| Привязки | 3 | Подключение и восстановление редактора, списка, checkbox и spinbox; чтение в readonly; запрет Actions в readonly |
| Наблюдение модели | 2 | Разрешённые JSON/PNG и новое типизированное изменение; запрет скрытого поля; отзыв разрешения; общие квоты; реальное завершение CPU-работы |
| Результаты команд | 5 | Локальная запись, отказ, задержанное и неопределённое подтверждение, отдельные квитанции последовательных вызовов |

Данные тестовые и локальные. Модель, WASM и внешнее приложение не нужны.

## Системные библиотеки Linux

Qt wheel требует нативных системных библиотек. Перед импортом Qt offscreen CI
устанавливает на Ubuntu `libegl1 libopengl0 libgl1 libxkbcommon0 libdbus-1-3 libfontconfig1`.
`QT_QPA_PLATFORM=offscreen` убирает требование сервера рабочего стола,
но не зависимости от общих библиотек. Первый публичный Actions-прогон завершился
ошибкой сбора тестов из-за отсутствия `libEGL.so.1`; тесты в нём не выполнялись.
Workflow теперь устанавливает зависимости явно.

Следующий прогон выявил другую особенность чистого checkout: родитель каталога
`--basetemp` должен существовать. CI теперь создаёт `.runtime` перед pytest.
Изменена только подготовка workflow, а не проверки или поведение библиотеки.
