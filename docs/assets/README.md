# Merovinger assets · EN / RU

The original geometric logo and MEROVINGER wordmark are shared across languages.
English: hero.svg, mechanics.svg and their PNG companions. Memory also includes context.svg.
Russian: hero.ru.svg, mechanics.ru.svg and their PNG companions; Memory also includes context.ru.svg.
Social cards: social-preview.png (EN), social-preview.ru.png (RU).
README.md uses English assets; README.ru.md uses Russian assets.

Логотип и название Merovinger одинаковы для обоих языков.
Файлы с суффиксом .ru содержат русские подписи; файлы без суффикса — английские.
Все собственные иллюстрации редактируются как SVG и доступны по лицензии MIT.
Данные на схемах и снимке Qt-примера — тестовые.
