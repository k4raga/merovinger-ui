## 0.1.0a1 — 2026-11-17

First public Merovinger UI alpha snapshot.

- Shared typed state/commands, SQLite runtime and managed Qt bindings.
- Explicit adoption of six Qt widget classes in QBoxLayout hosts.
- Read-only views with scoped grants.
- Policy-filtered model context and coherent approved PNG handoff.
- Explicit observation, CPU-worker and runtime cleanup.
- Standalone local-agent example and nine focused UI tests.

The distribution name is `merovinger-ui`. Import paths remain `agent_native`;
the library source is preserved from the verified snapshot. This publication
does not add a provider gateway or claim general application automation.
